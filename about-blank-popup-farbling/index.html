Farbling in an about:blank popup

A popup opened with window.open('') reports the device's real fingerprinting values, while this page reports randomized ones. An about:blank iframe is not affected.

Shields up, fingerprinting protection on, popups allowed. Test reads the values inside the popup; on an affected build they differ from this page. Control reads the popup's values from this page first; those should match.
